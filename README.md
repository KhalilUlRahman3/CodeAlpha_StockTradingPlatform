
# Stock Trading Platform

A Java-based console application that simulates a stock trading environment.

## Features

- Display available stocks and market prices.
- Buy and sell stocks using virtual money.
- Manage a personal stock portfolio.
- Calculate portfolio value and profit/loss.
- Maintain transaction history.
- Simulate stock market price changes.
- Track portfolio performance over time.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- LinkedHashMap
- Scanner
- Random
- Java Date and Time API

## Starting Balance

Rs. 100,000 (Virtual Money)

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open StockTradingPlatform.java.
3. Run the main() method.
4. Select options from the menu.
